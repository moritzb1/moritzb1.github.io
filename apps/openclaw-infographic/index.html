What is OpenClaw?purpose & basic architecture

An open-source, self-hosted personal AI agent created by Peter Steinberger (first released as “Clawdbot”). It runs 24/7 on your own computer or a cloud server.

A plain LLM only talks. OpenClaw gives the LLM a body: it reads files, uses tools, remembers you and acts on its own schedule.

5 key capabilities

Lives in your chat apps

One gateway connects many messengers – no new app to learn, the agent answers like a colleague.

multi-channel

Persistent memory

LLMs forget every chat. OpenClaw writes what matters into Markdown files and re-reads them – your “diary”.

MEMORY.md

Real actions

Runs commands, edits files, browses websites and sends messages – it does the task, not just describes it.

tools

Works proactively

A heartbeat wakes the agent regularly (default every 30 min) and cron jobs run tasks at set times.

heartbeat + cron

Delegates to sub-agents

Splits big jobs into parallel “clones”, each with a fresh context – faster and saves context window.

subagents

Skills & integrationshow the agent connects to tools and messaging apps

A skill is a folder with a SKILL.md file: a written playbook (SOP) for one job. The agent discovers skills automatically and loads one only when it fits the request. Ready-made skills come from the public registry ClawHub.

skills/weekly-brief/SKILL.md
---
name: weekly-brief
description: Monday marketing brief for the team
---
# Steps
1. Read KPIs from the campaign sheet
2. Compare this week vs. last week
3. Post a short summary to Telegram
Messaging channelsWhatsAppTelegramSlackDiscordiMessageSignal
Work toolsGmailGoogle CalendarNotionGitHubGoogle Sheetsweb browser
How the connection works
  • Channel adapters turn every message into one agent conversation
  • Tools are called through command line programs, APIs or MCP servers
  • API keys and logins are stored in the agent's own config

Safety & my takeawaypermissions, risks, evaluation

Risks

  • Broad permissions: shell, files, e-mail and keys on one always-on machine
  • Malicious skills: in Feb 2026, Koi Security found 341 of 2,857 ClawHub skills malicious (“ClawHavoc”)
  • Prompt injection: hidden text on a web page or in an e-mail can hijack the agent
  • Exposed instances & plain-text credentials on badly configured servers

Safeguards

  • Least privilege: separate accounts, only the tools a job needs
  • Sandbox: e.g. NVIDIA NemoClaw with the OpenShell runtime (GTC, March 2026)
  • Vetted skills only – ClawHub now scans uploads with VirusTotal, but that is “not a silver bullet”
  • Approval before sending, paying or deleting

My takeaway

OpenClaw shows the step from chatbot to colleague: memory, tools and a schedule turn an LLM into an agent that really saves time on recurring marketing work.

But it acts with my permissions. I would use it for read-only research and drafts first, keep a human approval step for anything public, and run it in a sandbox – never with my main accounts.
