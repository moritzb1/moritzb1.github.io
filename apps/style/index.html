How it works

Neural Style Transfer fuses the content of a photo with the style of an artwork (Gatys et al., CVPR 2015).

The original method optimises every image for minutes. Here each style is a small feed-forward CNN trained once with perceptual losses (Johnson et al., ECCV 2016), so one image takes a fraction of a second.

Browser-only: no Python backend. The models run with ONNX Runtime Web (WASM, multi-threaded) inside a Web Worker, so the page never freezes.

Models: ONNX Model Zoo fast neural style “-9” versions (candy, mosaic, rain princess, udnie, pointilism). Free for personal or research use.

+ 6 extra styles from Johnson's fast-neural-style (starry night, la muse, the scream, the wave, feathers, composition VII): converted from Torch7 .t7 to ONNX and checked against the original (max. difference 0.2 of 255 colour levels).
